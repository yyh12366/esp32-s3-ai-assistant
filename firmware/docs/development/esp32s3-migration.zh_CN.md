# ESP32-S3 N16R8 合并固件

此板型沿用合并版首页、AstrBot 对讲、小说、音乐、设置和 KK 监测，并在首页增加 **Video**。原 ESP32-C3 板型仍使用原显示和按键驱动。小说、音乐继续由合并仓库里的 relay 媒体服务提供。

| 硬件 | ESP32-S3 GPIO |
| --- | --- |
| ILI9341 CS / DC / RST / SCK / MOSI | 10 / 4 / 5 / 12 / 11 |
| ES8311 I2C SDA / SCL | 8 / 9 |
| ES8311 I2S MCLK / BCLK / LRCK | 16 / 17 / 15 |
| ESP32 发送 → 音频板 DIN；音频板 DOUT → ESP32 接收 | 7；18 |

ES8311 模块使用 5 V 供电、与 ESP32 共地；模块功放默认开启，不占用额外 GPIO。当前 S3 构建启用音频。对供电尚未确认的模块，在 S3 的 menuconfig 中关闭 `AV_S3_AUDIO_ENABLE`。未接电量计、背光调光脚或触控控制器，固件不驱动这些外设。

使用 ESP-IDF 5.5.3 构建：

```sh
cd firmware
./tools/build_firmware.sh esp32s3
```

合并镜像位于 `build/esp32s3/FoloToy-AI-Passport-full.bin`。S3 镜像使用 16 MB Flash、8 MB Octal PSRAM，并保留双 OTA 分区。已有 C3 镜像不能烧到 S3；给 S3 提供 OTA 时也要使用 S3 应用镜像。整包写入可能覆盖本机配置。

接好板后，使用 `idf.py -B build/esp32s3 monitor` 打开串口监视器，以电脑键盘代替实体按键：

| 键 | 操作 |
| --- | --- |
| `w` / `s` / `e` | 上 / 下 / 确认 |
| `W` / `S` / `E` | 对应长按 |
| `1` / `2` / `3` | 对应双击 |
| `r` / `t` | 在语音页按下 / 松开确认键；录音后按 `t` 发送 |

沿用设置中的蓝牙配网和中继地址；新板的设备标识默认与旧板不同，旧板的会话与配置不会自动迁移。

要播放视频，在首页进入 **Video**，退出串口监视器（Ctrl+]），再用原 USB 视频控制页选择视频。电脑端协议和视频目录保持不变。要回到首页，先关闭电脑播放器，再按开发板 RESET。视频模式与语音或监测分开运行，仍为无声 USB 播放。

触摸屏到货后，需要按实际型号、控制器和接线适配；现有触摸、实体按键和电量读数不属于本次实机验证范围。
