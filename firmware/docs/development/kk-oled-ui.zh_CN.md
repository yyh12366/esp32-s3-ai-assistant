# KK OLED UI 与硬件监测工具

本应用从本地 `main`（`488beda`）创建 `feature/kk-oled-ui` 分支，
以独立的单色仪器界面替换基线测试菜单启动流程，原有 demo 仅作为参考。

## 显示与职责边界

逻辑显示区为 120 × 160、每像素 1 bit，共 2,400 字节。绘图原语支持置位、
清除和 XOR，圆角光标逐像素反转下方文字及图标。BSP 将像素横纵各放大 2 倍，
输出到 240 × 320 ST7789P3，亮点映射为白色、OLED 青或琥珀黄 RGB565。
不使用抗锯齿或全屏 RGB565 缓冲。

`main/` 负责状态机、有界页面栈、动画、字体、页面、设置和应用工作任务；
`components/bsp/` 负责硬件访问。应用不启动 LVGL，不复用测试菜单外壳。
共享 ADC 和 I2C 仍由 BSP 管理。按键回调只投递事件，耗时存储和音频操作
在回调及渲染路径之外运行。

## 操作与设置

| 场景 | UP / DOWN | OK 短按 | OK 长按或双击 |
| --- | --- | --- | --- |
| 主菜单轮播 | 上一个 / 下一个图标 | 进入页面 | 保持主菜单 |
| 设置列表 | 上一行 / 下一行 | 打开编辑或返回 | 返回主菜单 |
| 编辑器 | 调节；数值长按连发 | 聚焦操作按钮 | 取消 |
| 弹窗按钮 | 选择取消 / 确定 | 执行焦点操作 | 取消 |
| 波形页 | 上一个 / 下一个数据源 | 无操作 | 返回主菜单 |
| 数据 / 关于页 | 只读 | 无操作 | 返回主菜单 |

四个入口是【数据监测】【波形监测】【系统设置】【关于本机】。数据页显示
电池 mV / V、电量、运行时间及实测 FPS。波形源为麦克风环境音量、GPIO0 按键
电压和明确标注的模拟混合正弦波。硬件读数不可用时不以合成数据冒充。

| 设置 | 范围 | 初始默认值 |
| --- | --- | --- |
| 屏幕亮度 | 10–100% | 80% |
| 按键提示音 | 关 / 开 | 开 |
| 刷新间隔 | 15–50 ms | 25 ms |
| 主题色 | 经典白 / OLED 青 / 琥珀黄 | 经典白 |

编辑器默认处于调节态，第一次短按 OK 聚焦底部操作按钮。取消时丢弃草稿并恢复
预览前亮度。确认提交 NVS 成功后才显示“设置已保存”，滑入后停留 1.2 秒再滑出；
提交失败显示错误。恢复出厂仅重置本应用配置，不清除其他 NVS 命名空间。
导航和动画不写 Flash。

## 验证

激活 ESP-IDF 5.5.3，在本工作区运行 `./tools/validate.sh`。统一门禁执行仓库
检查和宿主机测试，用 `sdkconfig.defaults` 生成隔离配置并构建，随后合并镜像、
验证分区布局和匹配的调试归档。可烧录产物为
`build/FoloToy-AI-Passport-full.bin`，烧录偏移为 `0x0`。

在统一仓库中使用 `./tools/build_firmware.sh kk_oled` 构建本版本，合并镜像位于
`build/kk_oled/FoloToy-AI-Passport-full.bin`。

宿主机检查覆盖纯导航、页面栈、弹窗操作、回滚、保存完成、长按连发、光标几何、
阻尼、裁剪和 XOR。宿主机渲染图可检查布局和字形覆盖，不能证明面板颜色、音频、
电气时序或真机动画流畅度。

## 上机验收

1. 启动精确匹配的已验证镜像，检查 USB 日志中的初始化失败、看门狗、最小堆及
   最大空闲块。确认出现全新主菜单且中文无缺字。
2. 反复进入所有页面，检查 2 倍像素、竖屏、黑底、主题色、XOR 文字切割、光标
   伸缩、滚动、弹窗缩放、开关滑动及 Toast。覆盖短按、快速双击，确认数值长按
   松手后停止连发。
3. 预览最低及最高亮度，分别用【取消】和长按 OK 退出，确认恢复。保存每项设置，
   等待成功提示，断电重启检查 NVS 恢复。
4. 检查按键声音、麦克风对环境声的响应、三个按键对 ADC 波形的影响和独立模拟
   波形模式。边导航边保存并听音，在刷新间隔两端测量响应。
5. 用仪器和实际充电状态核对电池读数；电量计缺失时应显示不可用。运行时间持续
   增长，FPS 反映实际帧时序。
6. 先取消恢复出厂，再确认一次，重启检查默认值。反复导航和保存，观察堆和响应。

编译成功不代表真机验收。烧录前需确认目标并获得该精确镜像的授权。合并烧录可能
重置 NVS；需保留配置时使用兼容的分段烧录。全片擦除或备份原固件不是前置条件。
详见[烧录数据策略](engineering/firmware-layout.zh_CN.md#烧录与已存数据)。
